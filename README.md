# 🏨 HotelManagement_Backend

A robust backend system built using **Express.js** and **MongoDB**, enabling hotel administrators to manage staff, authenticate users via JWT, and perform full CRUD operations on menu items and user profiles.

---

## 📌 Key Features

- 🧑‍🍳 User Registration & Login (JWT-Based Authentication)
- 🔐 Protected Routes with Role-Based Access Control (`Manager`)
- 🍽️ Full CRUD Operations on Menu Items
- 👥 View/Edit/Delete Hotel Staff (Chef, Waiter, Manager)
- ⚙️ Filter Data by Taste Type or Role

---

## 🧰 Tech Stack

- **Backend Framework**: Node.js, Express.js
- **Database**: MongoDB + Mongoose ODM
- **Authentication**: JWT (JSON Web Token)
- **Dev Tools**: dotenv, nodemon
